# Редактор каталога

Откройте `/admin` или ссылку «Редакторам» внизу списка мест. Админка загружается отдельным JS-модулем. Локальный адрес: http://127.0.0.1:5173/admin.

## Вход

Введите email, получите письмо и перейдите по ссылке в том же браузере. Регистрация через подтверждённую почту не выдаёт права редактора. Для первого входа отправка письма и подтверждение выполняются пользователем.

Владелец проекта назначает редактора через Supabase SQL Editor:

```sql
insert into private.admins(user_id)
select id from auth.users
where lower(email) = lower('EDITOR_EMAIL') and email_confirmed_at is not null
on conflict (user_id) do nothing;
```

После назначения нажмите «Проверить доступ». Не помещайте email редакторов в публичный код и не выдавайте права на основе user_metadata.

В облачном проекте Site URL настроен на `http://127.0.0.1:5173/admin`. Перед размещением приложения укажите HTTPS-адрес хостинга и точные разрешённые адреса возврата в Authentication → URL Configuration. Включение wildcard-доменов не требуется.

## Возможности

- Список объектов, постраничная загрузка по 50 записей, поиск и фильтр статуса внутри текущей страницы.
- Создание и редактирование объекта: названия, slug, описание, категория и город.
- Добавление города и провинции в справочники. Неопределённую географию можно оставить пустой в черновике.
- Координаты WGS84 и отдельное хранение исходных координат/системы каждого источника.
- Источники и фотографии по прямым URL с указанием автора, лицензии и страницы источника. Загрузка файлов в Storage пока не подключена.
- Записи проверки с подтверждающими ссылками и заметками.
- Публикация, снятие с публикации в черновик, архивирование без удаления.
- Предупреждение о несохранённых изменениях и защита от перезаписи более новой версии объекта.

Для изменения статуса существования/доступности нужна новая запись проверки. Для публикации нужны существование `exists`, дата проверки, координаты, город, категория и хотя бы один источник. Проверяйте соответствие доказательств и координат вручную: наличие ссылки само по себе не доказывает актуальность объекта.

## API

`POST /rest/v1/rpc/is_editor` возвращает роль текущего пользователя. Доступен только авторизованным пользователям.

`POST /rest/v1/rpc/admin_save_attraction` сохраняет объект, источники, фотографии и запись проверки одной транзакцией. Параметры: `p_place`, `p_sources`, `p_images`, необязательный `p_review`, `p_expected_updated_at` для редактирования существующего объекта. Изменённые другими редакторами версии отвергаются с `concurrent_edit`.

Функции используют SECURITY INVOKER и RLS. Анонимные вызовы запрещены; обычный пользователь не может вызвать сохранение. Журнал проверки получает пользователя из auth.uid(), а дату — из часов базы. Service-role ключ браузеру не нужен.

## Проверки

`npm run check` выполняет TypeScript, сборку и PostgreSQL-тесты. Тесты включают отказ анонимному/обычному пользователю, сохранение черновика, условия публикации, запись автора проверки, откат всех данных при ошибке и конфликт версий.
